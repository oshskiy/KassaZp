# Kassa ZP — Android-приложение для шиномонтажа

Полный проект Android Studio (Kotlin + Jetpack Compose + Room), работает офлайн.

## ⚠️ Важно про сборку

Я не могу скомпилировать и приложить готовый .apk-файл — в этой среде нет
Android SDK, эмулятора и доступа в интернет для скачивания Gradle-зависимостей.
Ниже — точная пошаговая инструкция, как собрать APK самому в Android Studio
(занимает 5-10 минут).

## Как собрать APK

1. Установите **Android Studio** (последняя стабильная версия), если ещё не установлена.
2. Откройте Android Studio → **Open** → выберите папку `KassaZP` (эту, с файлом `settings.gradle.kts`).
3. Дождитесь синхронизации Gradle (внизу справа появится прогресс-бар "Gradle sync"). Первая синхронизация скачает все зависимости и займёт несколько минут — нужен интернет.
4. Если Android Studio попросит обновить Gradle Plugin — соглашайтесь на предложенную версию.
5. Меню **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. После сборки внизу справа появится уведомление "APK(s) generated successfully" — нажмите **locate** или найдите файл сами:
   `app/build/outputs/apk/debug/app-debug.apk`
7. Переименуйте `app-debug.apk` в `Kassa ZP.apk`.
8. Скопируйте файл на телефон (через USB, Telegram, почту и т.д.) и установите — на телефоне нужно будет разрешить "установку из неизвестных источников".

Если сборка упадёт на ML Kit (`Could not resolve com.google.mlkit:text-recognition`) —
проверьте, что в `settings.gradle.kts` есть `google()` в списке репозиториев
(она уже добавлена в этом проекте) и что на компьютере есть интернет во время
синхронизации Gradle — сами файлы библиотек скачиваются с серверов Google.

## Что сделано

- **Касса**: переключатель День/Ночь, произвольное число строк ввода с типом
  (Обычная/ПД/Сварка/ПК), расчёт по вашим формулам и округление ЗП до 10₽,
  вывод в точном формате из задания, копирование в буфер, «Поделиться» текстом
  и PDF, автосохранение черновика между запусками (Room).
- **Работники**: список с накопительной суммой, добавление вручную, история
  заработка по каждому (дата+сумма+смена), редактирование/удаление записей.
- **Распознавание фото** (ML Kit, офлайн): для касс-листов — суммы с пометками
  ПД/Сварка/ПК; для смен — список имён (с диалогом подтверждения перед
  сохранением, новые имена добавляются автоматически).
- **Отчёт**: выбор месяца, список работников с местами 🥇🥈🥉 и сравнением
  с прошлым месяцем (🟢/🔴), столбчатая и круговая диаграммы, экспорт в PDF/CSV/текст.
- **Настройки**: проценты (День/Ночь/ПД/Сварка) с сохранением, сброс к
  стандартным значениям, опциональный PIN-код при входе.
- Material 3, тёмная/светлая тема по системной, крупные шрифты и кнопки,
  вибро-отклик на стандартных кнопках Compose уже встроен системой.

## Что стоит доработать (ограничения)

- **Распознавание рукописного текста** — ML Kit хорошо справляется с печатным
  и аккуратным почерком; неразборчивый почерк будет давать ошибки, поэтому
  везде результат распознавания показывается пользователю для проверки перед
  сохранением, а не сохраняется автоматически.
- **Графики** нарисованы вручную на Canvas (не через Vico/MPAndroidChart) —
  это осознанный выбор, чтобы не рисковать несовместимостью версий сторонней
  библиотеки при сборке. Выглядят просто, но работают надёжно.
- Формат вывода ЗП ("X₽ + Y₽ = Z₽") показывает округлённые до рубля доли
  и итог, округлённый до 10₽ по вашему правилу — если понадобится показывать
  копейки или иначе распределять округление между долями, это легко поменять
  в `Calculator.kt`.
- PIN-код хранится в открытом виде в DataStore (не хешируется) — этого
  достаточно для базовой защиты от случайного открытия, но не для серьёзной
  секретности.
- Иконка — простая векторная "шина/колесо", сгенерированная вручную; при
  желании можно заменить на файл через Image Asset Studio в Android Studio.
